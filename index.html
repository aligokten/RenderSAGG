RenderSAGG

Mimari render panelleri — mimariyi koru, sadece isteneni değiştir

Malzeme ve renk alternatifi paketleri

3D renderınızı yükleyin, değiştirmek istediğiniz yüzeylere tıklayarak numaralı bölgeler işaretleyin, her pakette o numaralara malzeme görseli yükleyip katalogdan malzeme ve renk seçin — “Versiyonu render et” alternatif render sahnesini üretir.

Paneli aç

Panel tarayıcıda çalışır: görselleriniz ve API anahtarınız hiçbir sunucuya gönderilmez, istek doğrudan tarayıcınızdan Google Gemini'ye gider. Anahtarınız yoksa Yerel demo sağlayıcısıyla akışın tamamını deneyebilirsiniz (görsel yapay zekâ ile üretilmez, malzeme değişmez).

Sunucu sürümü

Depodaki Node sürümü ek olarak ham render fotogerçekçileştirme ekranını, panel şifresini, saatlik üretim sınırını ve sharp/Lanczos ile daha keskin 4K yükseltmeyi içerir.

  • Kurulum: npm install && npm start → http://localhost:3000
  • Yayınlama: depodaki DEPLOY.md — Docker, Fly.io veya kendi sunucunuz
